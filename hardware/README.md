# Hardware design workspace

Status: DRAFT skeletons created 2026-11-12. These are editable starting projects,
not electrically complete or ready to fabricate.

- `sentry-pod/`: KiCad project and provisional 49 x 24 mm carrier-board outline.
- `pocket-keyfob/`: KiCad project and provisional 27 x 20 mm carrier-board outline.

The outlines are initial packaging placeholders. They are not final board sizes.
No footprints, copper routing, schematic nets, power circuits or component
placements have been released. Do not order these boards.

Open each `.kicad_pro` in KiCad PCB Editor. The matching `.kicad_pcb` file
contains a board outline only. Add schematic symbols and footprints only after
the exact Zero-board pad mapping and module connectors are reconciled against
the verified pinout records.
